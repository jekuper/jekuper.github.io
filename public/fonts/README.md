# Fonts

The design uses three commercial typefaces that cannot be redistributed:

| Family | Files |
| --- | --- |
| Spaced (Vultype) | `spaced.otf` |
| Alliance No.1 Light (Degarism Studio) | `alliance-no1-light.otf` |
| Aktiv Grotesk Corp (Dalton Maag) | `AktivGroteskCorp-{Light,LightItalic,Regular,Italic,Medium,MediumItalic,Bold,BoldItalic}.ttf` |

If you own licenses, drop the files here with these names. Without them the
page falls back to Space Grotesk and the system sans-serif.
